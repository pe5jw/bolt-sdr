Optimal Thetis Configuration for TCI Remote

This guide explains how to configure Thetis for optimal audio performance when using TCI Remote. We'll set up a dedicated TX profile specifically for TCI Remote so your normal shack settings stay perfectly intact.

1. Make a New Profile

First, go to Setup > Transmit in Thetis. Make sure you are currently using a perfectly working profile for your local operations.

Click on Save and name your new profile "TCI Remote".

2. Tweak Settings for Optimal Audio

Now that you have your new profile active, let's start tweaking everything for the best remote audio!

2.1 Equalizer Settings

From the main window of Thetis, open the Equalizer. Try to mimic these settings:

Preamp: 2dB

Equalizer sliders (from left to right):
10dB, 5dB, 1dB, -3dB, 1dB, 4dB, 6dB, 8dB, 11dB, 2dB

2.2 DSP Buffer Sizes

Next, go to Setup > DSP > Options. Change your buffer sizes as shown below. This helps avoid jittering streams over the network.

2.3 CFC Settings

Finally, go to the CFC tab under DSP Options. Mimic these exact settings:

Pre-Comp: 3dB

Equalizer (from left to right):
0dB, 3dB, 1dB, 0dB, 2dB, 0dB, 3dB, 0dB, 4dB, 0dB

Post EQ gain: -9dB

Equalizer (from left to right):
3dB, 0dB, 0dB, 0dB, 0dB, 0dB, 2dB, 3dB, 3dB, 4dB

3. Save and Automate Profile Switching

Go back to the Transmit tab and click Save to make sure all these tweaks are stored under your newly made "TCI Remote" TX profile.

Enable Auto-Switching in TCI Remote

Next, open TCI Remote on your device and go to the Config menu. Scroll down to find "TX Profile Switching".

Turn it ON and select the "TCI Remote" TX profile from the drop-down menu.

That's it! TCI Remote will now automatically switch back and forth between your "TCI Remote" profile when you connect, and restore your normal shack profile when you disconnect.

⚠️ IMPORTANT NOTE:
If you do not quit TCI Remote correctly (e.g., your browser force-closes or you suddenly lose connection), the app might not be able to send the command to switch your profile back. ALWAYS check if the correct TX profile is selected when you are back in the shack with your mouth at the dynamic microphone!

Test with these settings! While I don't want to claim these are the absolute "best" audio settings for every single voice, they are a very good start and work beautifully for me.
