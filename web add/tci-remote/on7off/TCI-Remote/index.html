Features

📡

IQ Panadapter

192 kHz wideband IQ spectrum with Blackman-Harris FFT, zoom up to 12x, greyline world map background, and SNR-expanded display for weak signals.

📊

Classic S-Meter

Analog needle S-meter with custom calibration, LED bar meter, and real-time dBm readout. Calibrated from S1 to S9+60.

🎙️

Full Transmit

PTT push-to-talk and toggle mode with 3-minute safety timer. MIC gain control, SWR and TX power meters with configurable scale.

🌊

Waterfall

Real-time waterfall display synced with the panadapter. Adjustable speed and FFT smoothing. Bandpass filter drag to tune.

📝

QSO Notepad

Built-in QSO logging with call, name, RST fields. ADIF export and Android share. Your log stays in the app between sessions.

📱

Mobile First

Portrait and landscape modes optimized for phones. Fullscreen immersive mode. Bandwidth-saving PF modes for mobile connections.

🔒

Safety Features

VFO lock, out-of-band TX protection, RX-to-TX mute, and permanent RX safety poll to prevent stuck transmitters.

🔊

Gapless Audio

48 kHz WebAudio with configurable lag threshold, automatic stream reset, and audio level meter. Works over 4G/5G.

🌍

All ITU Regions

Supports all amateur bands 160m–6m plus 11m CB. Widest band allocations across ITU Regions 1, 2, and 3.

For developers

Build TCI-compatible software

Want your SDR application to connect to TCI Remote out of the box? We publish a complete, open protocol reference — everything needed to implement TCI correctly. The TCI Remote Compactor connects as a standard TCI client, so standard protocol compliance is all that is required on your server side.

📡
TCI Protocol Reference
Open document →

Complete WebSocket protocol reference — server handshake sequence, all commands with parameters and direction, IQ and audio binary frame formats, full annotated connection example, and a compatibility checklist.

WebSocket TCI commands IQ & audio frames Checklist
Minimum requirements for compatibility
✓ WebSocket server, configurable port (default 50001)
✓ Send TCI init block on connect, ending with ready
✓ IQ stream at ≥ 96,000 Hz as binary float32 frames (192 kHz recommended)
✓ Audio stream at 48,000 Hz stereo float32 binary frames
✓ Echo all state changes — frequency, mode, PTT — to all connected clients
✓ Server-side TX watchdog — release PTT automatically if client drops
